# SHADOW RPG

A small landscape Android RPG demo.

## Build APK on GitHub (no Android Studio required)

1. Upload this project to a GitHub repository.
2. Open the repository's **Actions** tab.
3. Select **Build ShadowRPG APK** and choose **Run workflow**.
4. Wait for the build to finish successfully.
5. Open the completed workflow run and download the **ShadowRPG-debug-apk** artifact.
6. Extract the downloaded artifact and install the APK on an Android phone.

The workflow uses Java 17, Android SDK 35, Android Gradle Plugin 8.6.1, and Gradle 8.7.
